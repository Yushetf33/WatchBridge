How to get your code

So the codes go to real users and not bots, you first need the app and its free trial.

  1. Install WatchBridge TV from Google Play on your Android TV or Google TV.
  2. Open the app and start the free trial with your email (2 days, no card needed). The email must be the one you will type below.
  3. Come back here, type that same email and press the button when the countdown reaches zero. Each batch goes fast.
  4. Copy your code and redeem it on Google Play → ☰ menu → Redeem code, using the same Google account you use on the TV. It takes a few minutes to show up.
  5. Open WatchBridge TV, go to Subscription and tap "Verify subscription" with the same email. It will show Lifetime access. The app does not refresh by itself after you redeem, and there is no need to wait for the trial to end.

The code only works with the Google Play version of WatchBridge TV, not with the APK from GitHub. One code per email, device and network.
