Compatibility

Nuvio, Wuplay, Wholphin, SmartTube — you don't have to pick a favorite

WatchBridge TV doesn't lock you into one player. Whichever of these you already use — or if you're still deciding between two — it opens the exact recommended title there, every time. Switch apps anytime in Settings, no reinstall needed.

Not a review or a "which one is better" — that's genuinely up to your own catalog/UI preference. This page is about what each one does for you with WatchBridge TV specifically.

01General streaming

Nuvio vs Wuplay vs Stremio

All three organize content pulled from installed add-ons into a browsable movies/shows interface for Android TV. From WatchBridge TV's side they're functionally identical: a title is identified through TMDB and its exact page opens directly in whichever one you've set as your destination — no searching by name, no guessing.

Nuvio
Add-on-based media browser for Android TV. Instant open on Google TV, hold-and-confirm on Fire TV.
Wuplay
An add-on-based movies & shows browser for Android TV, same category as Nuvio. If you already have Wuplay installed on your Google TV or Fire TV, WatchBridge TV works with it out of the box: pick a recommendation on the home screen and it opens that exact title directly inside Wuplay, matched through TMDB — no searching by name.
Stremio
The best-known of the three, cross-platform beyond just Android TV. Same integration either way.

Using an outdated or unofficial build of Nuvio/Stremio? A recommendation click opening the app but landing nowhere is almost always that — updating to the latest build fixes it. See the troubleshooting guide for details.

02Your own server

Jellyfin vs Wholphin

Jellyfin is free, open-source, self-hosted media server software — you run it on your own hardware and it organizes your own library. Wholphin isn't a different server, it's a separate open-source client app that connects to that same kind of Jellyfin server — pick either one as your destination.

Because a self-hosted library has no universal catalog to link to directly, WatchBridge TV can optionally check your own server first — if the recommendation is already in your library, it opens straight to that exact title, no search needed. If it's not there, it falls back to your regular destination app.

Settings → "Check my Jellyfin first"

  1. Enter your server URL and an API key from your admin dashboard
  2. In your library → opens that exact title, in Wholphin or Jellyfin (your pick)
  3. Not there → falls back to Nuvio/Stremio/Wuplay/Plex as usual

03Free catalog

Plex

Plex works two ways here: as your own media server (same idea as Jellyfin, if that's how you use it), or through Plex's own free, ad-supported streaming catalog — no server of your own required. Either way, TMDB matching opens the exact recommended title directly.

04YouTube redirect

SmartTube vs TizenTube Cobalt

A separate toggle from your movies/shows player: YouTube recommendations on Google TV can be sent to SmartTube or TizenTube Cobalt instead of the stock YouTube app — pick whichever alternative client you already have installed. Fire TV isn't supported for this one; it's Google TV only.

SmartTube
Open-source YouTube client built for Android TV.
TizenTube Cobalt
Another open-source alternative YouTube client, same redirect support.

Pick one, several, or switch later

Whichever of these you're already using, WatchBridge TV works with it today. Changing your mind later is a Settings toggle, not a reinstall.
