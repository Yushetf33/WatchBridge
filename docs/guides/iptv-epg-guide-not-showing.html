IPTV guide (EPG) not showing or empty? How to fix it

The channels load but the programme grid is empty, or only some channels have a guide. This is almost always about where the guide data comes from, not about the player. Here is how to check it in WatchBridge TV.

How the guide gets its data

An IPTV list only contains channels. The programmes come from an XMLTV guide (an .xml or .xml.gz file). WatchBridge takes it from one of two places:

  • The one your list already declares (many M3U lists and Xtream Codes panels point to their own guide), or
  • The XMLTV link you paste in the optional EPG field when you add the list.

Programmes are then matched to your channels by id or by name.

Fixes, in order

  1. Press Refresh list. It reloads the channels and the guide. A large guide takes a moment to download.
  2. Add an XMLTV link. If your list declares no guide, ask your provider for its XMLTV (EPG) URL and paste it in the EPG field of the list.
  3. Check the link. Open the XMLTV URL in a browser on the same network. It should download an .xml or .xml.gz file, not an error page.
  4. Only some channels are empty? The guide file has no entry that matches those channels' ids or names. The fix is on the provider's side: ask for a guide that covers them.

Good to know

  • The guide goes back up to 48 hours and forward as far as the guide file reaches.
  • Each list keeps its own EPG setting. If you use several lists, check the one you are looking at.
WatchBridge doesn't provide lists or guide data. It reads the ones you bring.
