Wholphin and Jellyfin on Google TV: open recommendations in your library

Google TV recommends titles but opens them in the app they came from. WatchBridge TV can send them to your own Jellyfin or Wholphin library instead, or look in your server first and use another player only if the title is not there.

Two ways to use Jellyfin or Wholphin with WatchBridge TV

Jellyfin is free, self-hosted media server software; Wholphin is a separate open-source Android TV client for that same kind of server. Google TV doesn't know either of them, so by default a recommendation opens in the app it came from. WatchBridge TV catches that click and sends the title to your library in one of two ways:

  • As your player. Choose Jellyfin or Wholphin as the app to open titles in. WatchBridge opens the app and searches for the title.
  • As a first stop (recommended if you also use another player). Turn on My Jellyfin / Emby and add your server. If the recommended title is already in your library, WatchBridge opens that exact item. If it isn't, it falls back to the player you chose, such as Nuvio or Stremio.
WatchBridge doesn't provide or host any content. It only opens titles from your own server or from apps you already use.

What you need

  • A Google TV / Android TV device or a Fire TV, with Jellyfin or Wholphin installed.
  • For the first-stop option: your server address (for example http://192.168.1.10:8096) and an API key, created in the Jellyfin dashboard under API Keys.
  • WatchBridge TV, from Google Play (Google TV) or as an APK (see the install guide). 2-day free trial with no card, then €4.99 once.

Set it up

  1. Install and turn on WatchBridge. Follow the main setup guide; on Google TV that means enabling the Accessibility service once.
  2. Choose your player. In Settings, open Open movies and series in and pick Jellyfin or Wholphin.
  3. Optional: check your server first. In Settings, open My Jellyfin / Emby, enter the server URL and the API key, and save. The server type (Jellyfin or Emby) is detected automatically.
  4. Click a recommendation on the Google TV home screen. If it is in your library, it opens there.

What to expect

  • Jellyfin and Wholphin have no public catalogue like Nuvio or Stremio: they can only open what your library contains. If the title isn't there, there is nothing to open, which is why the "first stop" option plus a second player works well.
  • Matching is done by title, using the same TMDB lookup as the other players. A library entry with a very different name, or in another language, can fail to match.

If it doesn't work

  • The server isn't found. The TV must be able to reach the address you typed. Use the local IP and port (usually 8096), include http://, and check you are on the same network.
  • The API key is rejected. Create a new key in the Jellyfin dashboard and paste it again without extra spaces.
  • It opens the app but not the title. Check the title exists in your library with the same name, and that your library metadata is complete.
  • The troubleshooting guide covers the rest, by error code.
